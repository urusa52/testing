## 시험이 새로 찾아낸 11번째 버그 — 이번 점검의 최대 수확

**증상**: 위치 권한을 회수한 뒤 두 번째 출제 등록을 하면 등록 버튼이 영구히 잠기고 완료 화면이 영영 안 나옴.

**원인**: 권한이 '묻기' 상태일 때 `getCurrentPosition`은 성공도 실패도 반환하지 않고 무한 대기한다. `timeout` 옵션은 위치 획득에만 적용되고 **권한 대기에는 적용되지 않는다.** 실제 폰에서 사용자가 권한 팝업을 무시하거나 늦게 답해도 같은 일이 일어난다.

**수정 2겹**:
1. 모든 GPS 요청에 절대 마감시간(Promise.race, 6초) — 권한 대기 중에도 반드시 반환
2. 등록 처리 전체를 try/finally로 감싸 어떤 경로로든 버튼 복구

M5·M2에 적용. M1은 개발 도구라 후순위로 두되 통합 시 같은 처리를 한다.

**교훈**: 이 버그는 정적 검토가 아니라 "권한 회수 후 재등록"이라는 엣지 시나리오 시험에서만 나왔다. 진단 과정에서 시험 도구(Playwright)의 대화상자 처리 특성 때문에 오탐을 두 번 거쳤고, 페이지 내부 계측(추적 로그 주입)으로 확정했다.

- 엣지 시험 5종: 손상 파일 → 안내 후 정상 복귀 / 세로 PNG → 정상 처리 / 권한 회수 후 재등록 → 좌표 null 확인 / 12회 연속 판정 → 멈춤 없음, 통계 정상 갱신(12→24) / 스크립트 오류 0건
